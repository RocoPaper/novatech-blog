# Novatech Brand Package

This folder contains the official blue `N` identity for Novatech.

## Quick Selection

- Light website header: `logos/novatech-horizontal-light.svg`
- Dark website header: `logos/novatech-horizontal-dark.svg`
- Arabic light header: `logos/novatech-horizontal-ar-light.svg`
- Arabic dark header: `logos/novatech-horizontal-ar-dark.svg`
- Mobile navigation: `logos/novatech-mark.svg`
- Browser favicon: `logos/novatech-favicon.svg`
- Social avatar: `logos/novatech-social-avatar.svg`
- Black-only printing: `logos/novatech-monochrome-black.svg`
- White-only printing: `logos/novatech-monochrome-white.svg`

SVG is the master format and should be used whenever supported. It scales without quality loss.

See [`../DESIGN.md`](../DESIGN.md) for the full identity and interface guidance.
